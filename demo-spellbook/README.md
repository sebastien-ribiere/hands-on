# demo-spellbook

A consumer project attached to the Golden Thread.

    src/spells/
      elements/   air, water, fire
      protection/ shield, ward     <- bound by ARCH-001
      offense/    flame_lance      <- may use fire freely

Everything Golden Thread stores here is either the minimal manifest
(`golden-thread.json`, committed) or a rebuildable cache (`.golden-thread/`,
ignored). The corporate configuration is never copied into this project.
